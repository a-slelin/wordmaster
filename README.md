# WordMaster — тренажёр английских слов с колодами

**WordMaster** — это веб-приложение для изучения иностранных слов (в первую очередь английского) с помощью собственных и готовых колод карточек.  
Пользователь регистрируется, создаёт колоды, наполняет их карточками (слово + перевод) и тренируется, отслеживая прогресс.  
Приложение построено по принципу **REST API** с минимальным фронтендом, что делает его отличным учебным проектом для практики **Java + Spring + PostgreSQL**.

---

## 📌 Основные возможности

### 👤 Пользователи
- Регистрация / вход по email и паролю (сессия или JWT).
- Все данные привязаны к конкретному пользователю.

### 📚 Колоды
- Создание, редактирование, удаление колод.
- Каждая колода может содержать описание и любое количество карточек.
- Просмотр всех своих колод с количеством карточек в каждой.

### 🃏 Карточки
- Добавление, редактирование, удаление карточек внутри колоды.
- Поля: слово (русское), перевод (английский), транскрипция (опционально).
- Автоматическая статистика: сколько раз ответил правильно / неправильно, дата последнего повторения.

### 🧠 Тренировка (флэш-карты)
- Выбор колоды для тренировки.
- Карточки показываются в случайном порядке.
- Сначала видно русское слово, по нажатию кнопки открывается перевод.
- Кнопки **«Знаю»** и **«Не знаю»** — обновляют статистику карточки и сразу показывают следующую.
- Отображение прогресса: «Обработано X из Y».

### 📊 Статистика и бонусы
- Список **«сложных слов»** — карточки с наибольшим отношением ошибок к попыткам.
- **Слово дня** — случайная карточка из любой колоды, показывается на главной странице.
- Прогресс по каждой колоде (процент выученных слов).

### 🌐 Готовые колоды (публичные)
- Встроенный каталог популярных колод:
  - **Неправильные глаголы** (top 100)
  - **Фразовые глаголы**
  - **Самые употребляемые слова** (Oxford 3000)
  - **Английские идиомы**
- Любую публичную колоду можно **скопировать** в свой аккаунт одним нажатием.
- Пользователь может сделать свою колоду публичной (опционально).

## 🛠️ Технологический стек

### Бэкенд
- **Java 25**
- **Spring Boot 3** (Web, Data JPA, Security)
- **Spring Security** (для аутентификации и авторизации)
- **PostgreSQL** — реляционная база данных
- **Lombok** — сокращение шаблонного кода
- **Maven** — сборка и управление зависимостями

### Фронтенд
- **HTML5, CSS3** — аккуратный минимализм
- **Vanilla JavaScript (ES6)** — только необходимое: `fetch` для API, обновление DOM
- Многостраничная структура (без сложного SPA-роутинга) — каждая страница отвечает за одну функцию
