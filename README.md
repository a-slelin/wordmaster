## 🎯 О проекте

**WordMaster** — веб-приложение для изучения иностранных слов (в первую очередь английского, с прицелом на расширение до
других языков) с помощью системы карточек, объединённых в колоды.

Идея простая, но гибкая:

1. Пользователь создаёт **колоду** (например, "Неправильные глаголы" или "Слова из сериала Friends").
2. Наполняет её **карточками** — пара "слово / перевод" (+ опционально транскрипция).
3. Тренируется по колоде в режиме **флэш-карт**, отмечая, знает слово или нет.
4. Приложение само отслеживает статистику: какие слова даются тяжело, какие уже выучены.
5. Колоду можно сделать **публичной** — тогда любой другой пользователь может скопировать её себе и учиться по ней.

Проект задуман в первую очередь как **учебный** — практика связки **Java + Spring Boot + PostgreSQL** на не тривиальной,
но реалистичной предметной области: с аутентификацией, доступом к чужим данным (публичные колоды), агрегацией статистики
и REST API.

## 💡 Ключевая идея

В отличие от простых "списков слов", WordMaster построен вокруг **колод как единиц обмена**: колода — это не просто
список карточек одного пользователя, а потенциально переиспользуемый контент, который живёт своей жизнью в каталоге
публичных колод. Это добавляет в проект интересные архитектурные вопросы:

- Что происходит с копией колоды после того, как оригинал изменили?
- Как считать статистику по копии независимо от оригинала?
- Как ограничить права на публичные vs приватные колоды?

Это делает WordMaster не просто CRUD-приложением, а полигоном для отработки настоящих архитектурных решений.

## ✨ Основные возможности

### 👤 Пользователи и аутентификация

- Регистрация и вход по email + паролю.
- Аутентификация через сессии или JWT (см. раздел Security).
- Разграничение доступа: пользователь видит и редактирует только свои колоды, но может *читать и копировать* публичные.

### 📚 Колоды

- Создание, редактирование и удаление собственных колод.
- У колоды есть название, описание, язык (в будущем), флаг "публичная/приватная".
- Список своих колод с количеством карточек и процентом выученных слов в каждой.
- Возможность сделать колоду публичной и убрать её обратно в приватные.

### 🃏 Карточки

- Добавление / редактирование / удаление карточек внутри колоды.
- Поля карточки:
    - слово (на изучаемом языке или на родном — в зависимости от направления);
    - перевод;
    - транскрипция (опционально);
    - счётчик правильных ответов;
    - счётчик неправильных ответов;
    - дата последнего повторения.
- Массовое добавление карточек (в перспективе — импорт из CSV/txt).

### 🧠 Тренировка (флэш-карты)

- Выбор колоды для тренировки.
- Карточки выдаются в случайном порядке (с возможностью в будущем — по алгоритму интервального повторения, см. Roadmap).
- Сначала показывается слово, перевод скрыт — открывается по клику/тапу.
- Две кнопки после проверки себя: **«Знаю»** / **«Не знаю»** — сразу обновляют статистику карточки и показывают
  следующую.
- Индикатор прогресса сессии: «Обработано X из Y».
- Экран итогов тренировки по завершении колоды: сколько узнал, сколько ошибся.

### 📊 Статистика и «фишки»

- **Сложные слова** — топ карточек с наибольшим отношением ошибок к общему числу попыток (по всем колодам пользователя
  или по конкретной).
- **Слово дня** — случайная карточка на главной странице, обновляется раз в день.
- Прогресс по каждой колоде в процентах ("выучено" считается по порогу правильных ответов).
- Общая статистика пользователя: сколько слов выучено всего, сколько колод создано/скопировано.

### 🌐 Каталог публичных колод

- Встроенные "стартовые" колоды, доступные каждому новому пользователю:
    - **Неправильные глаголы** (Top-100)
    - **Фразовые глаголы**
    - **Самые употребляемые слова** (Oxford 3000)
    - **Английские идиомы**
- Любую публичную колоду (встроенную или созданную другим пользователем) можно **скопировать себе в один клик** — копия
  независима от оригинала.
- Поиск и фильтрация по каталогу (по названию, популярности — количеству копирований).
- Возможность отметить понравившуюся колоду (лайк) — как сигнал качества контента.

## 🏗️ Архитектура

Backend построен по классической слоистой архитектуре Spring-приложений:

```
Controller  →  Service  →  Repository  →  Database
    ↑              ↑
   DTO         Entity (+ Mapper между Entity и DTO)
```

- **Controller** — принимает HTTP-запросы, валидирует вход, вызывает сервисы, возвращает DTO.
- **Service** — бизнес-логика: создание колод, копирование публичных колод, подсчёт статистики, логика тренировки.
- **Repository** — доступ к данным через Spring Data JPA.
- **Entity / DTO + Mapper** — сущности БД не "утекают" наружу через API, для каждого запроса/ответа есть свой DTO.
- **Security** — фильтрует запросы, определяет текущего пользователя, проверяет права на ресурс (владелец колоды /
  публичный доступ на чтение).

## 🗃️ Модель данных

Черновая схема основных сущностей:

**User**

- id, email, passwordHash, createdAt

**Deck (колода)**

- id, title, description, ownerId (→ User), isPublic, sourceDeckId (nullable — ссылка на оригинал, если колода — чужая
  копия), createdAt

**Card (карточка)**

- id, deckId (→ Deck), word, translation, transcription (nullable), correctCount, incorrectCount, lastReviewedAt

**TrainingSession** *(планируется)*

- id, userId, deckId, startedAt, finishedAt, cardsTotal, cardsCorrect

> Отношение `Deck 1—N Card`, `User 1—N Deck`. Копия публичной колоды — это новая строка `Deck` с собственным набором
> `Card` и ссылкой `sourceDeckId` на оригинал (для будущей аналитики популярности).

## 🚀 Быстрый старт

> Проект в разработке — инструкция будет дополняться по мере готовности docker-конфигурации.

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/a-slelin/wordmaster.git
   cd wordmaster
   ```
2. Поднять PostgreSQL (через Docker):
   ```bash
   docker-compose up -d db
   ```
3. Настроить `application.yml` (URL БД, логин/пароль).
4. Собрать и запустить приложение:
   ```bash
   ./mvnw spring-boot:run
   ```
5. Открыть в браузере `http://localhost:8080`.
