# Лабораторная работа №3. Контекст и память агента

Курс «Современные технологии в программировании» · Тема 3
Проект: **WordMaster** — тренажёр иностранных слов с колодами карточек.
Основа — агент из лабораторной №2 (`agent/agent.py`), агентный цикл и инструменты сохранены.

## Шаг 0. Подготовка

Ветка `lab3` создана от состояния после лаб. 2.

| Что сделано | Зачем |
|---|---|
| `requirements.txt` и `.env.example` перенесены в `agent/`, `requirements.txt` переведён из UTF-16 в UTF-8 | структура из задания; pip и git корректнее работают с UTF-8 |
| `.gitignore`: `agent/workspace/*` + исключение `!agent/workspace/docs/` | рабочие файлы песочницы (`cards.json`, копия README) остаются локальными, а корпус для `search_docs` попадает в репозиторий |
| `.gitignore`: `agent/sessions/*.json`, папка держится через `sessions/.gitkeep` | личные диалоги не коммитим, фрагменты логов приводим в отчёте |
| `agent/workspace/docs/` — 5 документов проекта | корпус для поиска (шаг 5) |

Корпус `workspace/docs/`:

| Файл | Содержание |
|---|---|
| `about.md` | о проекте, стек, архитектура |
| `features.md` | возможности: колоды, карточки, статистика, каталог |
| `training.md` | правила тренировки: темы, тема по умолчанию, проверка ответа, порог «выучено» |
| `faq.md` | частые вопросы |
| `data-model.md` | модель данных приложения и формат `cards.json` агента |

В `training.md` намеренно есть факты, которых нет в коде и системном промпте (тема по умолчанию — `travel`,
порог «выучено» — 3 верных ответа). По ним в шаге 5 проверяется связка `search_docs` → доменный инструмент.
