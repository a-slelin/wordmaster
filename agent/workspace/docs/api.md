# REST API WordMaster

Все эндпоинты начинаются с /api и принимают и возвращают JSON. Кроме регистрации и входа, каждый запрос должен нести токен авторизации в заголовке Authorization: Bearer.

## Аутентификация
POST /api/auth/register создаёт пользователя по email и паролю. POST /api/auth/login проверяет пароль и выдаёт токен, с которым работают все остальные запросы.

## Колоды
GET /api/decks — список своих колод. POST /api/decks — создать колоду, PUT /api/decks/{id} — изменить, DELETE /api/decks/{id} — удалить вместе со всеми карточками. GET /api/decks/public — каталог публичных колод, POST /api/decks/{id}/copy — скопировать публичную колоду себе.

## Карточки
GET /api/decks/{id}/cards — карточки колоды, POST /api/decks/{id}/cards — добавить карточку. PUT /api/cards/{id} и DELETE /api/cards/{id} — изменить и удалить карточку.

## Тренировка и статистика
GET /api/training/{deckId}/next выдаёт следующую карточку, POST /api/training/cards/{id}/answer принимает ответ «знаю» или «не знаю». GET /api/stats/hard-words — сложные слова, GET /api/stats/word-of-the-day — слово дня, GET /api/stats/decks/{id}/progress — прогресс по колоде.

## Коды ошибок
400 Bad Request — тело запроса не прошло валидацию, например пустое название колоды или слово длиннее 100 символов.
401 Unauthorized — токен не передан или просрочен, нужно заново выполнить вход.
403 Forbidden — ресурс чужой: попытка изменить или удалить колоду другого пользователя.
404 Not Found — колода или карточка с таким id не существует.
409 Conflict — email уже занят при регистрации или колода уже скопирована этим пользователем.
429 Too Many Requests — превышен лимит: не больше 60 запросов в минуту с одного токена.
