# Безопасность и доступ

## Регистрация и вход
Пользователь регистрируется по email и паролю. Пароль никогда не хранится в открытом виде: в базе лежит только его хэш BCrypt (поле passwordHash). Минимальная длина пароля — 8 символов, email должен быть уникальным. После входа сервер выдаёт JWT-токен, который живёт 24 часа; по истечении срока нужно войти заново.

## Права на колоды
Владелец колоды может читать, изменять и удалять её и все её карточки. Чужую приватную колоду нельзя ни увидеть, ни скопировать: для постороннего она выглядит так, будто её не существует, и сервер отвечает 404, чтобы не раскрывать сам факт её наличия. Чужую публичную колоду можно только читать и копировать. Любая попытка изменить чужую колоду или карточку в чужой колоде отклоняется с кодом 403. Проверка прав выполняется в слое Service, а не только в контроллере: так правило не обойти через другой эндпоинт. Администратор может скрыть публичную колоду из каталога, если она нарушает правила, но не может менять её содержимое. Права проверяются на каждый запрос заново: токен говорит только о том, кто пользователь, а владелец колоды всегда берётся из базы по ownerId. Поэтому подмена id колоды в адресе запроса не даёт доступа к чужим данным.

## Удаление аккаунта
Пользователь может удалить свой аккаунт в настройках профиля. Вместе с аккаунтом удаляются все его колоды, карточки и статистика. Копии его публичных колод, которые успели сделать другие пользователи, остаются у них: копия независима от оригинала, у неё просто обнуляется ссылка sourceDeckId.

## Защита от перебора
После 5 неудачных попыток входа подряд вход для этого email блокируется на 15 минут. Общий лимит API — 60 запросов в минуту на токен, превышение даёт ответ 429.
