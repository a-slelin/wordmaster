# Каталог публичных колод

## Стартовые колоды
Каждому новому пользователю сразу доступны четыре встроенные колоды: «Неправильные глаголы» (Top-100), «Фразовые глаголы», «Самые употребляемые слова» (Oxford 3000) и «Английские идиомы». Их создаёт администратор, и они всегда публичные.

## Публикация своей колоды
Любую свою колоду можно сделать публичной переключателем «Публичная» в её настройках и в любой момент убрать обратно в приватные. Пустую колоду без карточек опубликовать нельзя. Уже сделанные другими копии после снятия с публикации остаются у их владельцев.

## Копирование
Публичную колоду копируют себе в один клик кнопкой «Скопировать». Копия получает нового владельца, свой набор карточек и обнулённую статистику, а в поле sourceDeckId запоминает оригинал. Одну и ту же колоду один пользователь может скопировать только один раз.

## Поиск, лайки и популярность
Каталог можно искать по названию и сортировать по популярности. Популярность колоды — число её копий, его считают по ссылкам sourceDeckId. Понравившейся колоде можно поставить лайк: это сигнал качества для других пользователей, лайк не копирует колоду.
