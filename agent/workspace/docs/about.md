# О проекте WordMaster

WordMaster — веб-приложение для изучения иностранных слов (в первую очередь английского) с помощью карточек, объединённых в колоды.

Пользователь создаёт колоду, наполняет её карточками «слово / перевод» и тренируется в режиме флэш-карт. Приложение само ведёт статистику: какие слова даются тяжело, а какие уже выучены.

Колоду можно сделать публичной — тогда другой пользователь может скопировать её себе. Копия независима от оригинала: изменения оригинала на неё не влияют.

Проект учебный: практика связки Java 25 + Spring Boot 3 + PostgreSQL. Фронтенд — HTML, CSS и Vanilla JavaScript без фреймворков.

Backend построен по слоистой архитектуре: Controller → Service → Repository → Database. Сущности БД не уходят наружу: для запросов и ответов используются DTO.
